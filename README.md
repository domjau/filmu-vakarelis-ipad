# Filmų vakarėlis – iPad katalogas

Naršomas filmų katalogas vaikui iPad'e. Vaikas pasirenka filmą, o tėvai suranda jį diske (SSD) ir paleidžia patys. Veikia be interneto.

## Kaip įdėti į iPad
1. iPad Safari atidarykite: https://domjau.github.io/filmu-vakarelis-ipad/
2. Spauskite **Dalintis** → **Pridėti prie pagrindinio ekrano**.
3. Vieną kartą atidarykite su internetu, kad katalogas išsisaugotų. Toliau veiks neprisijungus.

## Kaip atnaujinti katalogą
Katalogas (`catalog.js`) sugeneruojamas kompiuteryje, kuriame yra filmų biblioteka, naudojant `export_ipad_catalog.py` iš pagrindinio projekto. Įkėlus naują `catalog.js` į šį repo, iPad jį atsisiunčia pats, kai yra internetas.

Filmų failai čia niekada nekeliami, tik pavadinimai ir plakatai.
